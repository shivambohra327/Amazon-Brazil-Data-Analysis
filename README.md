# 📦 Amazon Brazil Data Analysis Using SQL

## 📌 Project Overview

This project is a **SQL-based e-commerce data analysis project** focused on Amazon Brazil. The analysis explores multiple aspects of the e-commerce ecosystem, including **customers, sellers, products, payments, reviews, orders, and fulfillment performance**.

The objective was to transform raw relational data into **meaningful business insights** by solving **14 real-world business questions** using SQL.

The project demonstrates how SQL can be used to analyze complex business data, identify performance patterns, and support **data-driven decision-making** across different areas of an e-commerce platform.

---

## 🎯 Business Objectives

The analysis was designed to answer important business questions related to:

* Seller and regional performance
* Product category revenue
* Customer purchasing behavior
* Payment method usage
* High-value customers
* Customer satisfaction and reviews
* Product performance
* Delivery and fulfillment efficiency
* Seller performance benchmarking
* Regional customer experience
* Order trends and demand patterns

---

## 🔍 Key Analysis Performed

### 🏪 Seller Performance Analysis

* Analyzed the **total number of delivered orders by seller state** to understand regional seller performance.
* Identified **sellers who registered but never fulfilled an order**.
* Compared seller performance against the **average seller** to identify high-performing sellers.
* Generated insights that can support seller activation and performance benchmarking.

### 📦 Product & Category Analysis

* Calculated **cumulative revenue for each product category over time** using SQL window functions.
* Identified the **top 5 revenue-generating product categories**.
* Identified products that have **never been ordered**.
* Used these insights to understand category performance and opportunities for product catalog optimization.

### 👥 Customer Analysis

* Analyzed customer order frequency across Brazilian states.
* Identified the **highest-spending customer** based on total purchase value.
* Examined regional customer purchasing behavior.
* Identified customers who placed orders but **never submitted a review**.

### 💳 Payment Analysis

* Identified the **most frequently used payment method**.
* Compared the **average order value across different payment types**.
* Used payment behavior to understand customer transaction preferences.

### ⭐ Customer Satisfaction Analysis

* Calculated the **average review score for each product category**.
* Identified Brazilian states with the **highest average customer review scores**.
* Analyzed customers who purchased products but did not leave reviews.
* Generated insights that can help improve customer experience and review participation.

### 🚚 Delivery & Fulfillment Analysis

* Calculated **median delivery time** between order placement and customer delivery.
* Used date calculations and window functions to analyze delivery performance.
* Identified potential opportunities for improving fulfillment efficiency and customer satisfaction.

### 📅 Order Trend Analysis

* Identified the **month with the highest number of orders** across the platform.
* Used order-date analysis to understand demand patterns.
* These insights can support demand forecasting, staffing, warehouse planning, and marketing campaigns.
